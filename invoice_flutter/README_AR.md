# نظام إدارة الفواتير الطبية — واجهة Flutter أصلية

## محتويات الحزمة
- `lib/` واجهة Flutter مكتوبة بـ Dart/Widgets، ولا تستخدم WebView أو HTML/CSS/JS.
- `android/` إعدادات Android الأساسية.
- `test/` اختبارات وظيفية بسيطة لبناء QR وفق TLV وتصدير CSV والتحقق من القيم.
- `server_original/` ملفات PHP + MySQL + React الأصلية كما وردت دون تعديل في قاعدة البيانات أو واجهة API، للرجوع إليها أو الرفع على الاستضافة.

## الوظائف المنقولة من واجهة HTML/React
1. تسجيل الدخول والخروج مع جلسات PHP وCSRF ودعم المدير والموظف.
2. لوحة التحكم: عدد الفواتير، الإيرادات، الضريبة، الإجمالي، العملاء، الوثائق وآخر خمس فواتير.
3. أرشيف الفواتير: بحث نصي + فلتر الفترة الزمنية + عرض وطباعة + تصدير CSV.
4. إنشاء فاتورة: الرقم التلقائي، العميل، الوثيقة التابعة للعميل، رقم التأشيرة، التاريخ، الوصف، الضريبة المحسوبة لحظيًا، وسائل الاتصال؛ جميع الحقول اختيارية.
5. إدارة العملاء: إضافة/تعديل/حذف.
6. إدارة وثائق التأمين: إضافة/تعديل/حذف، نوع الوثيقة، التواريخ والأقساط.
7. إعدادات الشركة: البيانات وVAT والتذييل ورفع شعار وختم (مع الحجم والتفعيل وموقعي الختم).
8. تغيير كلمة المرور.
9. سجل تدقيق المدراء.
10. الفواتير: عرض عربي RTL، شعار وختم، QR حقيقي TLV، وطباعة/PDF بالعربية.
11. مزامنة جميع عمليات الحفظ والتعديل والحذف من MySQL عبر `api.php`.

## التشغيل (Flutter SDK مثبت على الجهاز)
```bash
cd invoice_flutter
flutter create . --platforms=android
flutter pub get
flutter run --dart-define=API_BASE_URL=https://asampy.xo.je/api.php
```

`flutter create .` ضروري **مرة واحدة** لإكمال ملفات Flutter المولَّدة آلياً مثل Gradle wrapper وأيقونات التشغيل وملفات Android المحلية. وإذا عرض Flutter اقتراح الكتابة على ملفات معدلة، احتفظ بملفات مشروع هذه الحزمة (`lib` وملفات Android المعدلة) ولا تستبدل المنطق البرمجي. أمر البناء:
```bash
flutter build apk --release --dart-define=API_BASE_URL=https://YOUR_DOMAIN/api.php
```

## الربط بالخادم
- احتفظ بالـ PHP وMySQL على الاستضافة، واستخدم التطبيق فقط كعميل API.
- قبل فتح Flutter، افتح الرابط `https://YOUR_DOMAIN/api.php?action=session` في متصفح لتتأكد من نجاح استجابة JSON وأن قاعدة البيانات تم إعدادها.
- إذا كانت الاستضافة الحالية InfinityFree تمنع طلبات التطبيقات المباشرة بحماية/JS anti-bot، **فلن يعمل الاتصال من Android حتى تنقل `api.php` إلى استضافة تدعم REST API أو تسمح بطلبات الهاتف**. المشروع لا يتجاوز قيود مزود الاستضافة.
- استعمل HTTPS. لا تنقل كلمة مرور MySQL أو منطق المصادقة إلى التطبيق.
- غيّر كلمات مرور الحسابات الافتراضية من شاشة تغيير كلمة المرور.
- حافظ على نسخة احتياطية من MySQL، ولا ترفع `install.php` أو `database.sql` إلى مجلد عام بعد التثبيت.

## ملاحظات عن الخطوط والطباعة
- تم إنشاء QR قابل للمسح باستخدام TLV، بدل نمط canvas العشوائي في الواجهة القديمة.
- الطباعة تستخدم `printing` و`pdf`، وخط Cairo من `PdfGoogleFonts`، فيتطلب اتصالاً بالشبكة عند تحميل الخط لأول مرة. لم تُضمَّن ملفات خطوط داخل الحزمة.
- تختلف أبعاد الخطوط/الجداول والنوافذ قليلاً بين تصميم HTML وFlutter الطبيعي؛ الوظائف والنصوص والحقول الأساسية محافظة عليها، لكن لم يجر اختبار بصري pixel-by-pixel.
