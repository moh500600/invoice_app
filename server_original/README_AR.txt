المطلوب منك قبل الرفع:
1) افتح ملف config.php.
2) ابحث عن:
   define('DB_PASS', 'PUT_YOUR_MYSQL_PASSWORD_HERE');
3) استبدل PUT_YOUR_MYSQL_PASSWORD_HERE بكلمة مرور MySQL الحقيقية.
   لا تستخدم كلمة مرور حساب InfinityFree إلا إذا كانت هي نفسها كلمة مرور MySQL المعروضة في لوحة الحساب.

طريقة الرفع على InfinityFree:
1) افتح File Manager من لوحة InfinityFree.
2) ادخل مجلد htdocs الخاص بالنطاق asampy.xo.je.
3) ارفع محتويات هذا المجلد كلها داخل htdocs، وليس المجلد الخارجي فقط.
4) افتح في المتصفح:
   https://asampy.xo.je/install.php
5) اضغط «بدء تثبيت قاعدة البيانات».
6) بعد نجاح التثبيت افتح:
   https://asampy.xo.je/
7) احذف install.php و database.sql من الاستضافة بعد نجاح التثبيت.

مهم جداً:

- جميع حقول الفواتير والعملاء والوثائق وإعدادات الشركة اختيارية.
- البيانات محفوظة في MySQL، ولن تختفي عند تحديث الصفحة أو إغلاق المتصفح.
- لا تضع كلمة مرور MySQL في أي صورة أو رسالة عامة.

الملفات الأساسية:
- index.php: واجهة النظام.
- app.js: منطق واجهة React بعد تجهيزه للتشغيل مباشرة.
- api.php: جميع عمليات الحفظ والقراءة وتسجيل الدخول.
- config.php: إعدادات اتصال MySQL.
- db.php: إنشاء اتصال PDO آمن.
- database.sql: الجداول والبيانات الأولية.
- install.php: تثبيت قاعدة البيانات تلقائياً.
- .htaccess: إعدادات حماية أساسية.

في حال ظهور خطأ اتصال:
- تأكد من DB_HOST وDB_USER وDB_NAME وكلمة المرور.
- استخدم اسم المضيف sql112.infinityfree.com، ولا تستخدم localhost.
- يجب تشغيل ملفات PHP من داخل استضافة InfinityFree، وليس بالنقر عليها مباشرة من الهاتف أو الكمبيوتر.
