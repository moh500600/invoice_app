إصلاح مشكلة اختفاء / عدم ثبات البيانات
=====================================

ما تم إصلاحه:
1) كان يوجد index.html قديم يشغّل نسخة ببيانات داخل الذاكرة فقط، لذلك قد تظهر البيانات ثم تختفي عند تحديث الصفحة.
   أصبح index.html الآن يحوّل تلقائياً إلى index.php المرتبط بقاعدة MySQL.
2) تم إجبار الاستضافة عبر .htaccess على استخدام index.php كصفحة رئيسية.
3) بعد كل حفظ/تعديل/حذف، الواجهة تعيد قراءة البيانات من MySQL للتأكد أن المعروض هو المخزّن فعلياً.
4) حفظ إعدادات الشركة أصبح INSERT/UPDATE تلقائياً حتى لو كان سجل الإعدادات مفقوداً.
5) install.php يفحص جميع الجداول الأساسية بدلاً من جدولين فقط، ويعرض الجداول الناقصة لإصلاحها.
6) تم تعطيل التخزين المؤقت لملفات الواجهة وطلبات API لتجنب تشغيل نسخة JavaScript قديمة بعد رفع التحديث.

طريقة الرفع:
- ارفع محتويات هذا المجلد إلى htdocs واستبدل الملفات القديمة بالكامل.
- مهم: تأكد أن index.html القديم على الاستضافة تم استبداله بهذه النسخة، أو احذفه نهائياً.
- افتح install.php. إذا ظهرت "قاعدة البيانات جاهزة بالفعل" فلا تحتاج لإعادة إنشاء شيء.
- إذا ظهرت جداول ناقصة، اضغط "إنشاء / إصلاح قاعدة البيانات".
- بعد ذلك افتح الموقع من الرابط الرئيسي أو index.php.

اختبار الحفظ:
- سجل الدخول.
- أضف عميلاً تجريبياً.
- حدّث الصفحة F5 / Reload.
- يجب أن يبقى العميل موجوداً لأنه أصبح يُقرأ من MySQL.

ملاحظة:
- لا تحذف قاعدة البيانات الحالية إذا كان فيها بيانات فعلية.
- احتفظ بنسخة احتياطية من قاعدة MySQL قبل أي تغييرات كبيرة.
